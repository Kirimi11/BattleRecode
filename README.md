# 戦績帳（デッキトラッカー）

カードゲームの対戦成績・デッキ相性・獲得ポイントなどを記録するための個人用Webアプリです。

## できること

- 対戦結果の記録・編集・カレンダー表示
- デッキ相性分析、次回の使用候補の提案
- 相手デッキ図鑑（アイコン画像・フィニッシュ・サンプルリスト）
- 大会ごとの獲得ポイント・プロモ枚数の自動集計（期間: 4-9月 / 10-3月）
- 複数集計画面（タブ）、パスワード保護（PINパッド）
- データの書き出し・読み込み（暗号化対応）
- Gemini APIを使ったデッキ画像判定・チャット相談・使用率グラフの読み取り（任意）

データはすべて**この端末のブラウザ内（localStorage）**に保存されます。外部サーバーには送信されません
（Gemini APIキーを設定してAI機能を使う場合、画像やテキストがGoogleのサーバーに送信される点のみ例外です）。

## ローカルで動かす

```bash
npm install
npm run dev
```

`http://localhost:5173` が開きます。

## 無料でネット公開する（Vercelの例）

1. [vercel.com](https://vercel.com) にGitHubアカウントでログイン
2. このフォルダをGitHubリポジトリにpush
3. Vercelで「Add New Project」→ そのリポジトリを選択
4. Framework Preset は自動で「Vite」と認識されます。そのまま「Deploy」
5. 数十秒でURLが発行されます

Netlify・Cloudflare Pagesでもほぼ同じ手順（ビルドコマンド `npm run build`、公開ディレクトリ `dist`）で公開できます。

## Gemini APIキー（AI機能を使う場合のみ）

1. [Google AI Studio](https://aistudio.google.com/apikey) で無料のAPIキーを発行（クレジットカード不要）
2. アプリを開き、ヘッダーの「データベース」アイコン →「Gemini APIキー」欄に貼り付けて保存

キーはこの端末のブラウザ内にのみ保存されます。設定しなくても、AI機能以外のすべての機能は使えます。

## 注意点

- データはブラウザ（端末）ごとに独立しています。複数端末で同じデータを使いたい場合は、
  「データの書き出し・読み込み」機能でJSONファイルを介して手動で同期してください
- ブラウザのキャッシュ・サイトデータを消去すると、記録も消えます。定期的にバックアップ（書き出し）することをおすすめします
